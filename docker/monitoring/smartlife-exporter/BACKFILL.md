# 30-day power estimate (backfilled 2026-09-26)

`smartlife_power_watts_estimate` covers 2026-08-27 22:46 to 2026-09-26 21:06, 1 sample/min,
generated by `backfill_estimate.py` and loaded with `promtool tsdb create-blocks-from openmetrics`.
Prometheus merged the blocks into its own on load, so they cannot be removed by deleting folders.

Model: LLM Server = 0.991 x UPS 10.0.0.114 output; Office = that + 73.2 W;
Desktop = 1.031 x UPS 10.0.0.62 output; Server 168.9, Brocade 56.1, Optiplex 35.0, Desk 30.3,
TV and Audio 84.3, Internet and Den 7.2, NerdQaxe++ 0 (flat, measured 21:07-22:00 on Sep 26).

To remove: start Prometheus with --web.enable-admin-api, then
  curl -X POST -g 'http://localhost:2090/api/v1/admin/tsdb/delete_series?match[]=smartlife_power_watts_estimate'
  curl -X POST http://localhost:2090/api/v1/admin/tsdb/clean_tombstones
The dashboard falls back to real readings automatically (queries use `real or estimate`).
